Binary Search on Answer Space

function minEatingSpeed(piles, h) {
  function hoursNeeded(k) {
    let hours = 0;
    for (const pile of piles) hours += Math.ceil(pile / k);
    return hours;
  }

  let lo = 1, hi = Math.max(...piles);

  while (lo < hi) {
    const mid = Math.floor((lo + hi) / 2);

    if (hoursNeeded(mid) <= h) {
      hi = mid;       // mid works — try slower (smaller k)
    } else {
      lo = mid + 1;   // mid too slow — need faster (bigger k)
    }
  }

  return lo;  // minimum feasible eating speed
}

How Binary Search on Answer Space Works

This isn't searching for a value in an array — it's searching the space of possible answers for the smallest one that satisfies a condition. Koko needs to eat all the banana piles within h hours; at any given eating speed k, we can check in O(n) whether that speed is fast enough. The key insight: as k increases, the hours needed only ever decreases — that monotonic relationship is exactly what makes binary search valid here.

Step by step

  • The answer space is every possible speed k, from 1 to the largest pile size (eating faster than the biggest pile is never necessary).
  • Pick mid as a candidate speed (gold) and compute the total hours needed at that speed.
  • If the hours needed fit within h, this speed works — but maybe a slower speed also works, so try smaller: hi = mid.
  • If it doesn't fit, this speed is too slow — we need faster: lo = mid + 1.
  • When lo === hi, that's the minimum feasible speed.

Recognizing this pattern

Whenever a problem asks for the minimum (or maximum) value satisfying some condition, and that condition flips from false to true (or vice versa) exactly once as the value increases — a monotonic "yes/no" boundary — binary search on the answer works, even though there's no array being searched at all.

Complexity

Time: O(n log m) — n piles checked at each of the O(log m) candidate speeds, where m is the largest pile.
Space: O(1).

When is it used?

  • "Minimum capacity to ship packages within D days."
  • "Smallest divisor so a sum stays under a threshold."
  • Any optimization problem with a fast feasibility check and a monotonic answer boundary.

Compared to plain binary search

  • Binary search on answer space (this): searches a conceptual range of candidate answers, using a feasibility check instead of an array lookup.
  • Classic binary search: searches an actual sorted array for an exact matching element.
  • Both rely on the same core idea — a comparison that reliably eliminates half the remaining possibilities.
