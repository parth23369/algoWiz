DP on Strings Code

function lcs(a, b) {
  const m = a.length, n = b.length;
  const dp = Array.from({length: m+1}, () => new Array(n+1).fill(0));

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (a[i-1] === b[j-1]) {
        dp[i][j] = dp[i-1][j-1] + 1;   // chars match, extend diagonal
      } else {
        dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
      }
    }
  }

  return dp[m][n];   // length of LCS
}

LCS asks for the longest sequence of characters that appears in both strings, in order but not necessarily contiguous. It's the canonical "DP on strings" problem — the table is indexed by prefixes of each string, not by a single array position.

Step by step

  • Build dp[i][j] — LCS length between the first i characters of string A and the first j characters of string B.
  • Row 0 and column 0 are 0 (an empty prefix has no common subsequence with anything).
  • If A[i-1] === B[j-1], the characters match — extend the diagonal: dp[i][j] = dp[i-1][j-1] + 1.
  • Otherwise, take the best of skipping a character from either string: max(dp[i-1][j], dp[i][j-1]).
  • Once filled, backtrack from the bottom-right corner: a diagonal move means that character is part of the LCS.

Recurrence

dp[i][j] = dp[i-1][j-1] + 1  if A[i-1] = B[j-1],
else dp[i][j] = max( dp[i-1][j], dp[i][j-1] ).

Complexity

Time: O(m·n) — one cell per pair of prefixes.
Space: O(m·n), or O(min(m,n)) if only the previous row is kept (though then recovering the actual subsequence needs extra work).

When is it used?

  • diff tools and version control merges.
  • DNA/protein sequence alignment in bioinformatics.
  • Spell-checking and plagiarism-detection similarity scores.
  • Basis for related problems: Edit Distance, Shortest Common Supersequence.

Compared to other DP shapes

  • DP on strings (this): two indices, one per string — state space is a 2D grid of prefix pairs.
  • DP on subsequences (LIS): a single index plus a "last chosen value" constraint, not two independent strings.
  • Brute force: O(2^min(m,n)) — tries every subsequence of the shorter string.
