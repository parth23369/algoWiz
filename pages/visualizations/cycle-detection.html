DFS Cycle Detection Code

function hasCycle(graph, n) {
  const WHITE = 0, GRAY = 1, BLACK = 2;
  const color = new Array(n).fill(WHITE);

  function dfs(u) {
    color[u] = GRAY;  // in the current recursion stack

    for (const v of graph[u]) {
      if (color[v] === GRAY) return true;         // back edge — cycle!
      if (color[v] === WHITE && dfs(v)) return true;
    }

    color[u] = BLACK;  // fully explored, safe
    return false;
  }

  for (let u = 0; u < n; u++) {
    if (color[u] === WHITE && dfs(u)) return true;
  }
  return false;
}

How Cycle Detection Works

White — unvisited
Gray — in current recursion stack
Black — fully explored

Detecting a cycle in a directed graph needs more care than in an undirected one — you can't just track "visited," because revisiting an already-finished node through a different path is completely normal and not a cycle. What actually signals a cycle is looping back to a node that's still on the current path.

Step by step

  • Every node starts white (unvisited).
  • When DFS enters a node, color it gray — it's now on the active recursion stack.
  • For each outgoing edge to a neighbor: if that neighbor is gray, it's still on the current path — this is a back edge, and a cycle exists (red).
  • If the neighbor is white, recurse into it.
  • If the neighbor is black, it's already fully explored through some other path — safe to skip, no cycle there.
  • Once a node's entire subtree is explored with no cycle found, color it black and return.

Why three colors instead of two?

A simple visited/unvisited flag can't distinguish "finished and safe" from "currently in progress" — and that distinction is exactly what separates a harmless cross-edge from an actual cycle in a directed graph.

Complexity

Time: O(V + E) — standard DFS traversal cost.
Space: O(V) for the color array and recursion stack.

When is it used?

  • Deadlock detection in resource-allocation graphs.
  • Validating that a dependency graph is safe to topologically sort.
  • Detecting infinite loops in build systems or spreadsheet formulas.

Compared to other approaches

  • DFS 3-coloring (this): works for directed graphs; distinguishes back edges from cross/forward edges.
  • Union-Find: simpler and common for undirected graphs — a cycle exists the moment an edge connects two nodes already in the same set (used in Kruskal's MST too).
  • Kahn's algorithm (topological sort): a cycle exists if, after processing, not all nodes reached in-degree 0 — a BFS-flavored alternative to this DFS approach.
