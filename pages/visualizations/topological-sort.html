Kahn's Algorithm Code

function topoSort(graph, n) {
  const inDegree = new Array(n).fill(0);
  for (const u in graph) for (const v of graph[u]) inDegree[v]++;

  const queue = [];
  for (let v = 0; v < n; v++) if (inDegree[v] === 0) queue.push(v);

  const order = [];
  while (queue.length > 0) {
    const u = queue.shift();
    order.push(u);

    for (const v of graph[u]) {
      inDegree[v]--;
      if (inDegree[v] === 0) queue.push(v);
    }
  }

  // if order.length < n, the graph has a cycle (no valid ordering)
  return order;
}

How Topological Sort Works

A topological sort arranges the nodes of a Directed Acyclic Graph (DAG) in a line such that every edge points forward — from an earlier node to a later one. It only works on DAGs, since a cycle would force some node to come both before and after another.

Step by step (Kahn's Algorithm)

  • Compute each node's in-degree — how many edges point into it.
  • Any node with in-degree 0 (magenta) has no unmet prerequisites — it's ready to be placed.
  • Take a ready node, append it to the output order (green), and "remove" it from the graph by decrementing the in-degree of each of its neighbors.
  • Any neighbor whose in-degree just hit 0 becomes ready too, and joins the queue.
  • Repeat until every node has been placed. If some nodes never reach in-degree 0, the graph contains a cycle and no valid ordering exists.

Complexity

Time: O(V + E) — each node and edge is processed once.
Space: O(V) for the in-degree array and queue.

When is it used?

  • Build systems and task schedulers resolving dependency order.
  • Course prerequisite planning.
  • Spreadsheet formula recalculation order.
  • Package/module dependency resolution.

Compared to other approaches

  • Kahn's algorithm (this): BFS-style, using in-degree counts — naturally also detects cycles (leftover nodes).
  • DFS-based topological sort: runs a DFS and prepends each node to the order when its recursion finishes — same O(V+E) complexity, different bookkeeping.
  • Cycle detection: a natural prerequisite check often run first, since topological order is undefined for graphs with cycles.
