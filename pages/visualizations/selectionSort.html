Selection Sort Code

function selectionSort(arr) {
  const n = arr.length;

  for (let i = 0; i < n - 1; i++) {
    let minIdx = i;

    for (let j = i + 1; j < n; j++) {
      if (arr[j] < arr[minIdx]) {
        minIdx = j;      // found a new minimum
      }
    }

    if (minIdx !== i) {
      [arr[i], arr[minIdx]] = [arr[minIdx], arr[i]];  // one swap per pass
    }
  }
  return arr;
}

How Selection Sort Works

Sorted (in place)

Selection sort repeatedly finds the smallest remaining element and moves it to its final position. Unlike bubble or insertion sort, it does at most one swap per pass — all the work happens in the scanning, not the swapping.

Step by step

  • Assume the first unsorted element is the minimum (yellow).
  • Scan the rest of the unsorted portion, comparing each element to the current minimum candidate.
  • Whenever a smaller element is found, it becomes the new minimum candidate.
  • After scanning the whole unsorted region, swap the true minimum into the front of that region (red).
  • That front position is now sorted (green) — shrink the unsorted region by one and repeat.

Complexity

Time: O(n²) — always, regardless of input order (it doesn't adapt to partially sorted data).
Space: O(1) — sorts in place.
Stable: No — swapping the minimum into place can jump it past equal elements.

When is it used?

Rarely the fastest choice, but it minimizes the number of swaps — useful when writing to memory is much more expensive than reading (e.g. flash memory with limited write cycles).

Compared to other sorts

  • Selection Sort: O(n²) always — fewest swaps (O(n)), but not stable and not adaptive.
  • Insertion Sort: O(n²) worst case but O(n) on nearly-sorted input — adaptive and stable, though it can do many shifts.
  • Bubble Sort: O(n²) — also simple, but tends to do far more swaps than selection sort.
