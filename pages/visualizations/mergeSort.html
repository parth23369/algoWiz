Merge Sort Code

function mergeSort(arr) {
  let n = arr.length;

  // base case
  if (n <= 1) return arr;

  // split array
  let mid = Math.floor(n / 2);
  let left = arr.slice(0, mid);
  let right = arr.slice(mid, n);

  // recursive sort
  left = mergeSort(left);
  right = mergeSort(right);

  // merge sorted halves
  return merge(left, right);
}

function merge(left, right) {
  let result = [];
  let i = 0, j = 0;

  // compare and merge
  while (i < left.length && j < right.length) {
    if (left[i] < right[j]) {
      result.push(left[i]);
      i++;
    } else {
      result.push(right[j]);
      j++;
    }
  }

  // add remaining elements
  while (i < left.length) {
    result.push(left[i]);
    i++;
  }

  while (j < right.length) {
    result.push(right[j]);
    j++;
  }

  return result;
}

How Merge Sort Works

Sorted (in place)

Merge Sort divides the array into two halves, recursively sorts each half, and then merges the sorted halves back together. This process continues until the entire array is sorted.

Step by step

  • Divide the array into two halves from the middle.
  • Keep dividing each half recursively until each subarray has only one element.
  • Single-element arrays are already sorted.
  • Start merging: compare elements from the left and right subarrays.
  • Pick the smaller element and place it into a new sorted array.
  • Continue until all elements from both halves are merged.
  • Repeat merging step-by-step to build larger sorted arrays.
  • Finally, the entire array becomes fully sorted.

Complexity

Time: O(n log n) — array is divided (log n levels) and merged (n work per level).
Space: O(n) — extra space is needed for merging subarrays.
Stable: Yes — equal elements keep their relative order.

When is it used?

Used when stable sorting is required or when dealing with large datasets. It performs consistently well regardless of input order and is commonly used in external sorting (like sorting data from files).

Compared to other sorts

  • Merge Sort: O(n log n) — stable, but uses extra space
  • Quick Sort: O(n log n) average — faster in practice, in-place but not stable
  • Bubble Sort: O(n²) — much slower, mainly for learning purposes
