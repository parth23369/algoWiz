1D DP Code

function rob(houses) {
  const n = houses.length;
  const dp = new Array(n + 1).fill(0);
  dp[1] = houses[0];

  for (let i = 2; i <= n; i++) {
    dp[i] = Math.max(
      dp[i - 1],                 // skip house i-1
      dp[i - 2] + houses[i - 1]  // rob house i-1
    );
  }

  return dp[n];
}

You can't rob two adjacent houses (the alarm connects them), so for each house you face one choice: rob it and add its value to the best plan two houses back, or skip it and keep the best plan from one house back. That's a 1D DP — no grid needed, just a single rolling array.

Step by step

  • Define dp[i] as the max loot possible using the first i houses.
  • Base cases: dp[0] = 0 (no houses), dp[1] = houses[0].
  • For each further house, compare dp[i-1] (skip it) against dp[i-2] + houses[i-1] (rob it).
  • Keep the larger value as dp[i].
  • Once the array is full, backtrack from the end: if dp[i] equals dp[i-1], that house was skipped; otherwise it was robbed, and you jump back two houses.

Recurrence

dp[i] = max( dp[i-1], dp[i-2] + houses[i-1] ), with dp[0] = 0 and dp[1] = houses[0].

Complexity

Time: O(n) — one pass, one decision per house.
Space: O(n) for the full array, or O(1) if you only keep the last two values (a common space optimization for 1D DP).

When is it used?

  • Any "choose non-adjacent items to maximize a total" problem.
  • Scheduling with a cooldown/gap constraint.
  • Circular variants (House Robber II) and tree variants (House Robber III) build directly on this.

Compared to other DP shapes

  • 1D DP (this): state depends on a fixed number of previous positions in a single array — O(n) states.
  • 2D DP (e.g. Knapsack): state needs two dimensions (item index and capacity) — O(n·W) states.
  • Brute force: O(2ⁿ) — tries every subset of houses; DP collapses overlapping subproblems into O(n).
