Dijkstra Code

function dijkstra(graph, source) {
  const dist = {};
  for (const v in graph) dist[v] = Infinity;
  dist[source] = 0;

  const visited = new Set();

  while (visited.size < Object.keys(graph).length) {
    // pick the unvisited node with smallest dist
    let u = null;
    for (const v in graph) {
      if (!visited.has(v) && (u === null || dist[v] < dist[u])) u = v;
    }
    if (dist[u] === Infinity) break;  // remaining nodes unreachable

    visited.add(u);

    for (const [v, weight] of graph[u]) {
      if (dist[u] + weight < dist[v]) {
        dist[v] = dist[u] + weight;   // relax the edge
      }
    }
  }

  return dist;
}

How Dijkstra's Algorithm Works

Dijkstra's algorithm finds the shortest path from a source node to every other node in a weighted graph with non-negative edge weights. It's greedy: at each step it locks in the closest unvisited node, trusting that no shorter path to it could exist through a node that's farther away.

Step by step

  • Set the source's distance to 0 and every other node's distance to ∞.
  • Repeatedly pick the unvisited node with the smallest known distance (gold).
  • Relax every edge out of it: if going through this node gives a shorter path to a neighbor, update that neighbor's distance (magenta flash).
  • Mark the node finalized (green) — its shortest distance is now guaranteed correct.
  • Repeat until every reachable node is finalized.

Why this greedy choice works

Since all edge weights are non-negative, the closest unvisited node can never be reached by an even shorter path later through a currently-farther node — so it's safe to finalize it immediately, no backtracking needed.

Complexity

Time: O(V²) with a simple linear scan for the minimum each round (as shown), or O((V+E) log V) with a binary heap priority queue.
Space: O(V) for distances and the visited set.

When is it used?

  • GPS and road-network shortest-route finding.
  • Network routing protocols (e.g. OSPF).
  • Any weighted graph shortest-path problem with non-negative weights.

Compared to other algorithms

  • Dijkstra (this): O((V+E) log V) with a heap; fails with negative edge weights.
  • Bellman-Ford: O(V·E) — slower, but correctly handles negative weights and can detect negative cycles.
  • BFS: O(V+E) — equivalent to Dijkstra when every edge weight is exactly 1.
