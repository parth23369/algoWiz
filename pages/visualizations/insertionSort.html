Insertion Sort Code

function insertionSort(arr) {
  for (let i = 1; i < arr.length; i++) {
    const key = arr[i];
    let j = i - 1;

    // shift elements greater than key one position right
    while (j >= 0 && arr[j] > key) {
      arr[j + 1] = arr[j];
      j--;
    }

    arr[j + 1] = key;   // insert key into its correct spot
  }
  return arr;
}

How Insertion Sort Works

Sorted (in place)

Insertion sort builds the sorted array one element at a time, the way most people sort a hand of playing cards: pick up the next card and slide it into its correct place among the ones you're already holding.

Step by step

  • Treat the first element as a sorted "hand" of size 1.
  • Take the next element as the key (yellow).
  • Compare it to elements before it, shifting each larger one right (red) to make room.
  • Stop shifting once you find an element ≤ the key, and drop the key into that gap.
  • Everything to the left of the current position is now sorted (green) relative to itself.
  • Repeat for every remaining element until the whole array is sorted.

Complexity

Time: O(n²) worst case, but O(n) on nearly-sorted input — very few shifts are needed.
Space: O(1) — sorts in place.
Stable: Yes — equal elements never swap past each other.

When is it used?

Great for small arrays or nearly-sorted data (its adaptive behavior means fewer shifts when input is already mostly ordered). Many library sort implementations switch to insertion sort for small sub-arrays inside a larger quicksort/mergesort.

Compared to other sorts

  • Insertion Sort: O(n²) worst case, O(n) best case — adaptive, stable, in-place.
  • Selection Sort: always O(n²) regardless of input order — no adaptive benefit, and not stable.
  • Merge Sort: O(n log n) always, but needs O(n) extra space and isn't adaptive.
