Bubble Sort Code

function bubbleSort(arr) {
  let n = arr.length;

  // outer loop: n-1 passes
  for (let i = 0; i < n - 1; i++) {

    // inner loop: compare neighbours
    for (let j = 0; j < n - 1 - i; j++) {

      // if left > right → swap
      if (arr[j] > arr[j + 1]) {
        let temp  = arr[j];
        arr[j]    = arr[j + 1];
        arr[j + 1] = temp;
      }
    }
  }
  return arr;
}

How Bubble Sort Works

Sorted (in place)

Bubble Sort repeatedly steps through the list, compares adjacent elements, and swaps them if they're in the wrong order. After each full pass, the largest unsorted element "bubbles up" to its correct position at the end.

Step by step

  • Start at index 0. Compare arr[0] and arr[1].
  • If arr[0] > arr[1] → swap them.
  • Move to index 1. Compare arr[1] and arr[2]. And so on.
  • After one full pass, the largest element is at the end — it's sorted.
  • Repeat for the remaining n−1 elements, then n−2, and so on.
  • Stop when no swaps happen in a pass — array is sorted.

Complexity

Time: O(n²) — two nested loops, each running up to n times.
Space: O(1) — sorting happens in-place, no extra array needed.
Stable: Yes — equal elements never swap past each other.

When is it used?

Almost never in production — it's too slow for large data. But it's the best algorithm to teach sorting because the logic is completely transparent: you can watch every comparison and every swap happen, step by step.

Compared to other sorts

  • Merge Sort: O(n log n) — much faster, but uses O(n) extra space
  • Quick Sort: O(n log n) average — in-place but not stable
  • Bubble Sort: O(n²) — slow, but simple and educational
