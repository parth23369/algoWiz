DP on Subsequences Code

function lengthOfLIS(nums) {
  const n = nums.length;
  const dp = new Array(n).fill(1);   // each element is a subsequence of 1

  for (let i = 1; i < n; i++) {
    for (let j = 0; j < i; j++) {
      if (nums[j] < nums[i]) {
        dp[i] = Math.max(dp[i], dp[j] + 1);
      }
    }
  }

  return Math.max(...dp);
}

How Longest Increasing Subsequence Works

Current index i
Comparing against j < i
Part of the LIS

LIS asks for the longest run of elements — not necessarily adjacent — that strictly increases. Unlike LCS, there's only one array here, but the state at index i depends on comparing it against every earlier index, which is what makes this a "DP on subsequences" pattern rather than plain 1D DP.

Step by step

  • Define dp[i] as the length of the longest increasing subsequence ending exactly at index i.
  • Every element starts with dp[i] = 1 (itself, alone).
  • For each i, look back at every j < i: if nums[j] < nums[i], index i could extend the subsequence ending at j.
  • Take dp[i] = max(dp[i], dp[j] + 1) across all valid j, and remember which j gave the best extension (a parent pointer).
  • The answer is the maximum value anywhere in dp[]; backtrack through parent pointers from that index to recover the actual subsequence.

Recurrence

dp[i] = max( dp[i], dp[j] + 1 ) for every j < i where nums[j] < nums[i]; answer = max(dp).

Complexity

Time: O(n²) for this tabulation approach (every pair i, j).
Space: O(n) for the dp array.
A patience-sorting + binary search variant brings time down to O(n log n), at the cost of a less direct backtrack.

When is it used?

  • Box-stacking and envelope-nesting problems.
  • Patience sort and card-game solitaire strategy.
  • Finding longest chains in scheduling or version/dependency graphs.

Compared to other DP shapes

  • DP on subsequences (this): one array, but each state compares against all previous states — O(n²) pairs.
  • 1D DP (House Robber): each state only depends on a fixed constant number of previous states — O(n) total.
  • DP on strings (LCS): two independent indices over two different sequences, forming a 2D grid.
