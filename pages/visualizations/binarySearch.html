Binary Search Code


// Iterative Binary Search
function binarySearch(arr, target) {
  let left = 0, right = arr.length - 1;

  while (left <= right) {
    let mid = Math.floor((left + right) / 2);

    if (arr[mid] === target) return mid;

    if (arr[mid] < target)
      left = mid + 1;
    else
      right = mid - 1;
  }
  return -1;
}

How Binary Search Works

Binary Search is a highly efficient search algorithm used on sorted arrays. It works by repeatedly dividing the search interval into half.

At each step:

  • Compare target with the middle element
  • If equal → element found
  • If smaller → search in left half
  • If larger → search in right half

Time Complexity: O(log n)
Space Complexity: O(1)

This makes Binary Search extremely fast for large datasets.
