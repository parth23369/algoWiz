Partition DP Code

function minCut(s) {
  const n = s.length;
  const isPal = Array.from({length:n}, () => new Array(n).fill(false));

  // isPal[i][j] true if s[i..j] is a palindrome
  for (let len = 1; len <= n; len++) {
    for (let i = 0; i + len - 1 < n; i++) {
      const j = i + len - 1;
      if (s[i] === s[j] && (len <= 2 || isPal[i+1][j-1])) {
        isPal[i][j] = true;
      }
    }
  }

  const cutDp = new Array(n).fill(Infinity);
  for (let i = 0; i < n; i++) {
    for (let j = 0; j <= i; j++) {
      if (isPal[j][i]) {
        cutDp[i] = Math.min(cutDp[i], j === 0 ? 0 : cutDp[j-1] + 1);
      }
    }
  }

  return cutDp[n-1]; // minimum cuts needed
}

How Palindrome Partitioning Works

The goal is to split a string into the fewest possible pieces where every piece is a palindrome. This is partition DP: instead of a fixed grid over two sequences, the state is "where do I place the next cut," and each decision partitions the remaining string into independent sub-problems.

Step by step

  • Phase 1 — precompute palindromes: fill isPal[i][j] for every substring, built up by increasing length: a substring is a palindrome if its ends match and the inside (if any) is also a palindrome.
  • Phase 2 — find minimum cuts: define cutDp[i] as the fewest cuts needed to partition s[0..i] into palindromes.
  • For each i, try every possible last piece s[j..i]: if it's a palindrome, then cutDp[i] = min(cutDp[i], cutDp[j-1] + 1) (or 0 cuts if j = 0, since the whole prefix is one palindrome piece).
  • Backtrack from cutDp[n-1] to recover exactly where each cut falls.

Recurrence

isPal[i][j] = s[i]=s[j] AND (j-i<2 OR isPal[i+1][j-1])
cutDp[i] = min over palindromic s[j..i] of ( j=0 ? 0 : cutDp[j-1] + 1 )

Complexity

Time: O(n²) — O(n²) to build the palindrome table, O(n²) to compute cuts.
Space: O(n²) for the palindrome table, O(n) for cutDp.

When is it used?

  • Text segmentation problems (splitting into valid "words" or structures).
  • Matrix Chain Multiplication and Burst Balloons are the same partition-DP shape over intervals instead of palindromes.
  • Any "split into k pieces, minimize/maximize something per piece" problem.

Compared to other DP shapes

  • Partition DP (this): a decision at index i chooses a cut point j, splitting the problem into independent left/right pieces — the defining trait of interval/partition DP.
  • DP on strings (LCS): compares two full sequences step by step; no notion of "cutting" one sequence into independent chunks.
  • 1D DP (House Robber): each state depends on a fixed lookback, not on trying every possible split point.
