Greedy Code

function canCompleteCircuit(gas, cost) {
  let tank = 0, totalSurplus = 0, start = 0;

  for (let i = 0; i < gas.length; i++) {
    const diff = gas[i] - cost[i];
    tank += diff;
    totalSurplus += diff;

    if (tank < 0) {
      // can't reach the next station from `start`
      start = i + 1;   // greedy: try starting fresh from here
      tank = 0;
    }
  }

  return totalSurplus >= 0 ? start : -1;  // -1 = no valid start exists
}

How Gas Station Works

Final answer — valid starting station

Stations are arranged in a circle, each giving some gas and costing some gas to reach the next one. You need to find a starting station from which you can complete the full loop without your tank ever going negative. The greedy insight: if you run out of gas trying to reach station i+1, no station between your current start and i could have worked either — so jump straight past all of them.

Step by step

  • Track a running tank (since the current candidate start) and a totalSurplus (across the whole circuit).
  • At each station, add gas[i] - cost[i] to both.
  • If tank ever drops below 0, the current start can't work — reset tank to 0 and move the candidate start to the very next station (magenta).
  • After the full loop, if totalSurplus >= 0, the last candidate start is guaranteed to work (green) — otherwise no valid start exists anywhere.

Why skip past every station in between?

If you can't reach station i+1 starting from station s, then for any station s' between s and i, the tank when leaving s' would only be smaller or equal — since you'd have had less "head start" surplus. So none of those intermediate stations could possibly work either, and it's safe to jump straight to i+1.

Complexity

Time: O(n) — a single pass around the circuit.
Space: O(1) — just a few running counters.

When is it used?

  • Circular scheduling and routing feasibility checks.
  • Any "does a valid starting point exist" problem over a cyclic sequence of gains/costs.
  • Warm-up problem for prefix-sum and Kadane's-algorithm-style reasoning.

Compared to other approaches

  • Greedy (this): O(n) — one pass, skips provably-invalid starts instead of checking them.
  • Brute force: O(n²) — try every station as a start and simulate the whole loop from there.
