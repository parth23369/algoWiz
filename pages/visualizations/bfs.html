BFS Code

function bfs(root, key) {
  if (!root) return null;

  const queue = [root];
  const visited = new Set();

  while (queue.length > 0) {
    const node = queue.shift();

    if (visited.has(node.id)) continue;
    visited.add(node.id);

    if (node.value === key) return node;

    if (node.left)  queue.push(node.left);
    if (node.right) queue.push(node.right);
  }

  return null;
}

Breadth-First Search (BFS) is a graph/tree traversal algorithm that explores all nodes at the current depth before moving on to nodes at the next depth level. It explores level by level, hence the name.

Step by step

  • Start at the root node.
  • Mark it as currently visiting (yellow).
  • Enqueue its children (left first, then right).
  • Dequeue a node and explore it.
  • If the node matches the search key, mark it found (green).
  • After exploring all children, mark the node visited (red).
  • Backtrack up when a subtree is fully explored.

Complexity

Time: O(n) — every node is visited at most once.
Space: O(h) — h is tree height; the recursion stack goes as deep as the tree.

When is it used?

  • Finding a path between two nodes.
  • Topological sorting of a DAG.
  • Detecting cycles in a graph.
  • Solving maze and puzzle problems.
  • Pre/in/post-order tree traversals.

Compared to other algorithms

  • BFS: O(n) — explores level by level; better for shortest path in unweighted graphs.
  • Dijkstra: O((V+E) log V) — shortest path in weighted graphs.
  • A*: O(b^d) — heuristic-guided; optimal path in weighted graphs.
