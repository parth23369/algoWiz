What is Backtracking?

Backtracking is a problem-solving strategy that builds a solution incrementally, one choice at a time, and abandons ("backtracks" from) a partial solution the moment it becomes clear it cannot possibly lead to a valid or optimal answer.

The general pattern is:

  • Choose: pick the next candidate for the current position.
  • Explore: recurse forward as if that choice were correct.
  • Un-choose: if the recursion doesn't pan out, undo the choice and try the next candidate.

Backtracking is essentially a refined brute force: instead of generating every complete candidate solution and checking it at the end, it checks constraints as early as possible and prunes entire invalid branches of the search tree before wasting time exploring them further.

Applications of Backtracking

The following are some standard problems solved using backtracking:

N-Queens places N queens on an N×N chessboard so that no two attack each other, backtracking the instant a placement creates a conflict.
Rat in a Maze finds a path from the top-left to the bottom-right of a grid, retreating from dead ends to try a different route.
Permutations generates every possible ordering of a set of elements by trying each unused element in turn for the next position.
Subsets (Power Set) generates every possible subset of a set by making an independent include/exclude decision for each element.
Combination Sum finds every combination of reusable candidate numbers that sums exactly to a target, pruning branches the moment the running sum overshoots.
