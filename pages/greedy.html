What is Greedy Algorithm?

Greedy algorithms are a class of algorithms that make locally optimal choices at each step with the hope of finding a global optimum solution. But before understanding how it leads to a globally optimal solution and what is the difference between sub-optimal solution, we need to explore how any choice on the given input data affects the runtime of the algorithm.

If there are n input processes ordered in a certain way, such that each input i takes t i time to complete, then the total time taken will be:

$$\sum_{i=1}^{n} \sum_{j=1}^{i} t_j$$

That is for a process to complete, it needs to wait for all the processes that are before it to complete. So the time taken for process i is equal to the sum of all the processes that are before it. Thus making a simple choice of arranging the processes such that processes with lowest finish time are executed first ensures that while it is being executed, the other processes do not have to wait for much longer. We can extend this example to include the weights of processes as well which is a valid scenario considering we assign the processes a priority in real time as well. In that case sorting them in decreasing order of their weights will be the correct choice. Thus a simple change, at each step on our input data, leads to a optimal solution which runs in optimal time complexity.

We can now procede to understand how this simple choice leads to a globally optimal solution, and what is a globally optimal solution? are there any other choices available to us? See, every choice that we make at each step is a greedy choice, and the solution that we get from these choices is a greedy solution. But not all greedy solutions are globally optimal solutions. There might be sub-optimal solutions as well, as we only considered a restricted set of input and our choice returns a solution on it but for input outside that range it fails and this solution is sub-optimal, solution that works on all inputs is a globally optimal solution. So we need to work out on our knowledge of the problem and the input data to understand if the solution we are getting is a globally optimal solution or not.

Some problems where we use Greedy Algorithms are:

  • Fractional Knapsack Problem
  • Activity Selection Problem
  • Job Sequencing Problem
  • Huffman Coding
  • Prim's and Kruskal's Algorithm for Minimum Spanning Tree
  • Dijkstra's Algorithm for Shortest Path

Now Greedy Algorithms are not always optimal, for example for minimam jumps to reach a target step, the greedy choice is to take the maximum jump possible at each step. But this does not always lead to a globally optimal solution. For example, if we have an array of jumps [2, 3, 1, 1, 4], the greedy choice would be to take the maximum jump of 4 from index 0, but this would lead us to index 4 which is not the target step. So we need to be careful while using Greedy Algorithms and check if they are optimal for our problem or not. Thus we need Dynamic Programming here to solve the problem optimally.
